# mini-store-next

Мини-приложение магазина на Next.js с использованием TypeScript, App Router и mock API.

## Что реализовано

- страница со списком товаров `/products`
- страница детального просмотра товара `/products/[id]`
- загрузка данных через `fetch`
- обработка состояния загрузки через `loading.tsx`
- обработка ошибок через `error.tsx`
- вынесенная карточка товара `ProductCard`
- вынесенная галерея товара `ProductGallery`
- вынесенный информационный блок товара `ProductInfo`
- вынесенный блок характеристик `ProductSpecs`
- вынесенное форматирование цены через `formatPrice`
- кнопка возврата к списку товаров
- базовая адаптивная стилизация

## Стек

- Next.js
- TypeScript
- App Router
- CSS
- Mock API

## Структура проекта

- `app/layout.tsx` — корневой layout приложения
- `app/page.tsx` — главная страница / редирект
- `app/products/page.tsx` — список товаров
- `app/products/error.tsx` — обработка ошибок страницы списка
- `app/products/loading.tsx` — состояние загрузки списка
- `app/products/[id]/page.tsx` — страница товара
- `app/products/[id]/error.tsx` — обработка ошибок страницы товара
- `app/products/[id]/loading.tsx` — состояние загрузки страницы товара
- `components/ProductCard.tsx` — карточка товара
- `components/ProductGallery.tsx` — галерея товара
- `components/ProductInfo.tsx` — информационный блок товара
- `components/ProductSpecs.tsx` — блок характеристик товара
- `lib/api.ts` — функции запросов к API
- `lib/formatPrice.ts` — форматирование цены
- `types/product.ts` — типы товара
- `db.json` — mock API данные

## Функциональность

### Страница списка товаров
На странице списка отображаются:
- изображение товара
- название
- цена и валюта
- категория
- рейтинг
- остаток на складе
- ссылка на страницу деталей

### Страница товара
На странице деталей отображаются:
- название товара
- основное изображение
- дополнительные изображения
- цена
- описание
- категория
- бренд
- артикул
- рейтинг
- остаток на складе
- характеристики из `specs`

## Особенности реализации
- проект структурирован по принципу разделения ответственности (components / lib / types)
- данные загружаются с использованием `fetch` и вынесены в отдельный слой (`lib/api.ts`)
- тип товара вынесен в отдельный файл
- интерфейс списка и деталки разбит на небольшие переиспользуемые компоненты
- форматирование цены вынесено в `formatPrice`
- для маршрутов используются отдельные `loading.tsx` и `error.tsx`


## Улучшения в дальнейшем

Mock API будет доступен по адресу:

`http://localhost:3000/products`
