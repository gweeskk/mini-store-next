# mini-store-next

Мини-приложение магазина на Next.js с использованием TypeScript, App Router и mock API.

## Что реализовано

- страница со списком товаров `/products`
- страница детального просмотра товара `/products/[id]`
- загрузка данных через `fetch`
- обработка состояния загрузки
- обработка ошибок загрузки через `error.tsx`
- отображение основных характеристик товара
- кнопка возврата к списку товаров
- базовая адаптивная стилизация

## Стек

- Next.js
- TypeScript
- App Router
- CSS
- Mock Server

## Структура проекта

- `app/layout.tsx` — корневой layout приложения
- `app/page.tsx` — главная страница / редирект
- `app/products/page.tsx` — список товаров
- `app/products/error.tsx` — обработка ошибок страницы списка
- `app/products/loading.tsx` — состояние загрузки списка
- `app/products/[id]/page.tsx` — страница товара
- `app/products/[id]/error.tsx` — обработка ошибок страницы товара
- `app/products/[id]/loading.tsx` — состояние загрузки страницы товара
- `lib/api.ts` — функции для запросов к API
- `types/product.ts` — типы товара
- `db.json` — mock API данные

## Функциональность

### Страница списка товаров
На странице списка отображаются:
- изображение товара
- название
- цена и валюта
- категория
- рейтинг
- остаток на складе
- ссылка на страницу деталей

### Страница товара
На странице деталей отображаются:
- название товара
- основное изображение
- дополнительные изображения
- цена
- описание
- категория
- бренд
- артикул
- рейтинг
- остаток на складе
- характеристики из `specs`

## Запуск проекта

### 1. Запустить Mock Server
Поместить `db.json` в корень проекта и запустить Mock Server в VS Code.

Mock API будет доступен по адресу:

`http://localhost:3000/products`
